# v0.1 — Single-choice Test Lifecycle

## Goal

Demonstrate one complete local lifecycle in which an Author publishes a Single-choice Item and Test, then a Candidate takes the Test immediately and receives a Result.

## Included use cases

- [Author publishes a Single-choice Item](../domain/use-cases/author-publishes-single-choice-item.md)
- [Author publishes a Test](../domain/use-cases/author-publishes-test.md)
- [Candidate completes a Test immediately](../domain/use-cases/candidate-completes-test-immediately.md)

## Explicitly excluded

- Scheduling, slots, capacity reservation, cancellation, and rescheduling.
- Test Session history and Result-details view.
- Multiple item types, test sections, adaptive testing, and QTI import/export.
- Proctoring, payments, accommodations, and offline delivery.
- Production authentication, authorization, and deployment concerns.

## Done when

- The included lifecycle runs locally from start to Result.
- A Candidate can answer one Single-choice Item and submit the Test.
- The lifecycle is covered by end-to-end tests.
