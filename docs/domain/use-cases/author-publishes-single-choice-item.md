# Author Publishes a Single-choice Item

- **Actor:** Author
- **Goal:** Make a valid Single-choice Item available for inclusion in a Test.
- **Status:** Proposed for v0.1

## Preconditions

- The Author can create and edit Items.

## Main flow

1. The Author creates a Draft Item.
2. The Author enters the Item content, answer options, and the Correct Answer.
3. The Author requests publication.
4. The system validates the Item.
5. The system changes the Item status to Published.

## Success

An Item in Published status is available to Test Assembly.

## Out of scope for v0.1

- Item review and approval workflows.
- Rich media, complex interactions, and item import/export.
