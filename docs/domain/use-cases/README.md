# Use Cases

Use cases describe stable user goals and domain behavior. They are living documents: update an existing use case when its flow or rules evolve, and create a new one only when a distinct user goal emerges.

User stories and implementation tasks belong in the issue tracker. A release document declares which use cases are included in a version.
