# Candidate Completes a Test Immediately

- **Actor:** Candidate
- **Goal:** Complete a selected Test without scheduling and receive a Result.
- **Status:** Proposed for v0.1

## Preconditions

- The Candidate has selected a Test in Published status that is available to them.

## Main flow

1. The Candidate requests to start the Test now.
2. The system starts the Test.
3. The Candidate answers each Item.
4. The Candidate submits the Test.
5. The system makes the Result available.
6. The Candidate views the Result.

## Success

The submitted Test is scored and its Result is available to the Candidate.

## Out of scope for v0.1

- Scheduling, slots, capacity reservation, and rescheduling.
- Proctoring, payments, accommodations, and offline delivery.
