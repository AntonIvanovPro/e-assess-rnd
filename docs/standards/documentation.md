# Documentation Standards

## Markdown file size

Markdown files must not exceed 50 lines. Split longer material into focused documents and link between them.

## Root README

The root `README.md` must not exceed 50 lines.

Keep it focused on the project purpose, current scope, and getting started. Put detailed design material in `docs/`, architecture decisions in `docs/adr/`, and engineering conventions in `docs/standards/`.

## Whitespace

Do not use trailing whitespace in Markdown files.

Do not use two trailing spaces to force a line break. Use paragraphs, blank lines, lists, or tables instead.
